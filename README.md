# PointPilot

PointPilot is a Windows 11 desktop travel-rewards optimizer. It combines your points balances, transfer-partner network, award observations, manual capture, and historical pricing to recommend the best way to book a trip.

## Key capabilities

- Portfolio-aware flight and hotel optimization
- Manual capture for restricted airline/hotel sites
- Historical award-price observations and public benchmarks
- Transfer ratio + transfer-bonus modeling
- Saved trip alerts
- Local persistent user data
- GitHub Releases + automatic application updates

See README-WINDOWS.md for Windows installation, GitHub release setup, and update behavior.
