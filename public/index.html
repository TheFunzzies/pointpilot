Live award data — seats.aero

A seats.aero Pro membership includes a personal API key (Settings → API) for non-commercial use. The same key powers live flight search (20+ airline programs) and live hotel search through rooms.aero (Hilton, Hyatt, IHG, Marriott, Choice, Wyndham, I Prefer), each with about 1,000 calls/day. The key is stored only on this PC.

Cash fares — Travelpayouts & Google Flights

A free Travelpayouts partner token (Profile → API token) powers cash price search, price alerts and the deals feed. An optional SerpApi key (free: 250 searches/month) adds live Google Flights prices, Google's low/typical/high rating and business-class cash prices.
